Environment variables

Set secrets in Render → Environment. Never paste real values into code, README files or GitHub.

VariablePurpose
APP_ENCRYPTION_KEYFernet key used to encrypt stored LinkedIn tokens. Do not change after accounts are connected.
LINKEDIN_CLIENT_ID / LINKEDIN_CLIENT_SECRETLinkedIn developer app credentials.
LINKEDIN_REDIRECT_URIExact HTTPS callback URL shown above.
DATABASE_URLPersistent PostgreSQL URL recommended for cloud deployment.
GEMINI_API_KEY, GROQ_API_KEY, CEREBRAS_API_KEYAI text generation providers. Configure at least one provider.
OPENAI_API_KEYOptional paid API key for current image generation endpoint.

Important setup checks

LinkedIn publishing requires the correct developer product and member-posting permission (typically w_member_social). Each connected profile must authorize the same LinkedIn app. Publishing remains manual and approval-gated.

Cloud environment variables

Set these in your hosting provider's secret/environment settings. Do not commit real values to Git.

  • GEMINI_API_KEY — Google AI Studio key
  • APP_ENCRYPTION_KEY — Fernet key used to encrypt the stored LinkedIn token
  • LINKEDIN_CLIENT_ID and LINKEDIN_CLIENT_SECRET — LinkedIn developer app credentials
  • LINKEDIN_REDIRECT_URI — exact HTTPS callback URL above
  • DATABASE_URL — persistent PostgreSQL URL recommended for cloud deployment
  • LINKEDIN_API_VERSION — supported YYYYMM version available to your app
  • SCHEDULE_HOUR=8, SCHEDULE_MINUTE=0, APP_TIMEZONE=Asia/Kolkata

Important setup checks

LinkedIn publishing works only if your LinkedIn developer app has the required product and member-posting permission (typically w_member_social). OAuth approval does not guarantee API product access. Confirm the current API version and scopes in LinkedIn's developer portal before going live.

Research feeds are configurable. Job search results are leads only; verify vacancies on the employer's official careers site before publishing. This app does not scrape private LinkedIn pages or use browser-password automation.

Cloud environment variables

Set these in your hosting provider's environment settings. Do not commit real values to Git.

  • APP_ENCRYPTION_KEY — Fernet key used to encrypt stored LinkedIn tokens
  • LINKEDIN_CLIENT_ID and LINKEDIN_CLIENT_SECRET — LinkedIn developer app credentials
  • LINKEDIN_REDIRECT_URI — exact HTTPS callback URL above
  • DATABASE_URL — persistent PostgreSQL URL recommended for cloud deployment
  • LINKEDIN_API_VERSION — supported YYYYMM version available to your app

Important setup checks

LinkedIn publishing works only if your LinkedIn developer app has the required product and member-posting permission (typically w_member_social). Each connected profile must authorize the same LinkedIn app. Confirm API access and scopes in LinkedIn's developer portal.

Disconnecting one profile removes only that account's saved token. Other connected profiles remain available.
